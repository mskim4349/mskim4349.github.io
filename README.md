# mskim4349.github.io

Personal academic homepage of Minseok Kim — Postdoctoral Researcher, Department of Mechanical Engineering, UNIST.

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme. Served via GitHub Pages at <https://mskim4349.github.io>.

## Local build

```bash
bundle install
bundle exec jekyll serve
```
